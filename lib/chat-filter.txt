# The server's chat filter (lib/chatfilter.js): typed chat, Jam-a-Gram
# messages, Jammer Wall posts and bios. A message that breaks a rule here
# reaches nobody, and its sender is told it was not sent (a bio is not
# saved, and one saved before is not shown). Players cannot turn this
# off (unlike the client's own filter). It is read again when this file
# changes: no restart needed.
#
# One rule to a line; lines starting with # are comments. Capitals do not
# matter. Messages are read the way people dodge filters: digits and signs
# standing in for letters (4ss, a$$, n00b), letters drawn out (fuuuck), and
# words spelled out a letter at a time (f u c k, f.u.c.k).
#
#   word            that word on its own ("ass", not "class" or "assume")
#   word*           any word starting with it ("fuck*": fucking, fucker)
#   *word*          any word with it anywhere inside (for words that never
#                   turn up inside innocent ones)
#   two words       those words one after the other
#   a|b|c           any one of them
#   a + b           a, then b as the very next word
#   a .. b          a, then b at most 4 words later ("send .. nudes" catches
#                   "send me some nudes", but not "nudes, send")
#   a & b           both somewhere in the same message, in any order
#   ?               any one word (a name: "fuck + ? + ass" catches
#                   "fuck johns ass")
#   !word           in a | list: but not this word ("?|!it" is any word
#                   but "it"). A slot of only these takes up no word:
#                   "a + !up" is a, not followed by "up" (or ending there)
#
# These combine: "fuck|screw + you|u + in|up + the|your + ass" is one rule.
# Apostrophes are dropped before matching, so write "ill" for "i'll".
# Prefer + over .. and & : the looser the rule, the more ordinary messages it
# catches by accident ("fuck .. you" would also catch "i dont give a fuck
# about you").
